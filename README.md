# est57/homebrew-tap

Homebrew formulae for [Echoproof](https://github.com/est57/echoproof).

```bash
brew install est57/tap/echoproof
```

Supports macOS (Apple Silicon and Intel) and Linux (x86_64 and arm64).

The formula updates itself: a scheduled workflow picks up each new Echoproof release, tests it with `brew install` and `brew test`, and commits it.
